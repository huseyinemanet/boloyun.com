# Bol Oyun

Bol Oyun, Türkçe odaklı mini oyun portalıdır.

- Domain: https://boloyun.com
- Repository: https://github.com/huseyinemanet/boloyun.com.git
- Stack: Next.js, TypeScript, Tailwind CSS, Supabase

## Geliştirme

```bash
npx -y pnpm@11.7.0 dev
```

Yerel adres:

```txt
http://localhost:3000
```

## Kontrol

```bash
npx -y pnpm@11.7.0 typecheck
npx -y pnpm@11.7.0 build
```
